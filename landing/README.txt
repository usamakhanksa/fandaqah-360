FANDAQAH - STANDALONE WEBSITE

Open index.html by double-clicking it. No npm, Node.js, installation, build
command, internet connection, or local server is needed to browse the site.

Pages:
  index.html               Home
  features.html            Features
  features-v2.html         Features V2
  fandaqah-360.html         Fandaqah 360 landing page (brand typography)
  mega-menu-features.html  Mega-menu showcase
  pricing.html             Packages
  about.html               About
  blog.html                Journal
  contact.html             Contact
  privacy.html             Privacy information
  terms.html               Terms information
  features/<module>.html   One page per feature (20), English
  ar/features/<module>.html  The same 20 pages in Arabic
  sitemap.xml              All indexable pages, with English/Arabic alternates

Keep the assets folder alongside the HTML files. You can move or copy this
entire landing folder to another computer or any ordinary static web host.

All images, fonts, Motion and the bundled Three.js animation are local.
Webfonts are embedded in the CSS for compatibility with direct file opening.
El Messiri, Montserrat and Almarai are used on the 360 landing page.

External login/social links need internet access. The demo and package
requests are sent to the Fandaqah CRM (internet needed; if it cannot be
reached, the form offers an email instead). The newsletter form prepares an
email request in your email app. The feature pages have full Arabic versions;
on the other pages Arabic covers the primary labels, headings, the request
form, the package comparison and the legal pages.

The feature pages are generated by tools/build-landing.py from
tools/landing_features.py in the repository; edit those, not the HTML.
