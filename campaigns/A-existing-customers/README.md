# Campaign A · Existing customers

**Goal:** turn existing Fandaqah accounts into paid Fandaqah 360 upgrades through an upgrade review.
**Landing route:** `https://usamakhanksa.github.io/fandaqah-360/?utm_campaign=A_existing_upgrade_2610…` → opens `/existing-customers/` (see `links.csv`).
**Call to action:** Check my upgrade offer · تحقّق من عرض الترقية

## Buyer
| | |
|---|---|
| Who | Owner, GM or finance manager who already uses Fandaqah |
| Trigger | Renewal, an unused module, repeated manual work, a request for better reporting |
| Main objection | Paying again for tools they may not need |
| What answers it | A personal review of the current plan, only the modules that fit, and the launch-price offer (1 year, optional second year at the same rate) |

## Audience and exclusions
- Verified existing customers only. Personalise with current plan, renewal date and modules in use.
- Exclude customers already on the same offer.
- Route unresolved service complaints to account care **before** any upgrade message.

## Channels (in this order)
1. **Account manager** conversation and message (`am_message`).
2. **Permissioned email** and **WhatsApp** (`email_1`, `wa_template_1`); only contacts with recorded permission for that channel.
3. **First-party remarketing** on Meta for eligible audiences only (`ad_v1_ar`, `ad_v2_ar`). Do not spend broadly to reach customers we can contact directly.

The device screens in the creatives are illustrative. Before publishing, swap in a **real Fandaqah dashboard** beside the
three modules (accounting, purchasing, housekeeping) with sample data, as the playbook asks.

## Sales handoff
Confirm before any proposal: **account ID, current term, included modules, any approved credit or proration.**
The form sends the account ID and the modules the customer selected on the page. Never promise that remaining subscription
value will be refunded automatically.

## Scorecard (report separately from B–D)
Completed upgrade reviews · proposals · paid upgrades · collected cash. Track invalid numbers, bounces and opt-outs separately.
**First test:** headline v1 vs v2 only; same audience, offer, format and CTA. Do not call a winner from a few clicks.
